# 每日交易记录约定（西瓜枭）

> 位置：`E:/Trade/TradingAgents/trading_journal/`
> 启动：2026-10-14。用户会提前发「准备」（交易计划），执行后再发实际成交，由 Agent 合并记录。
> **执行纪律见 `docs/trading_execution_protocol.md`（决策与执行分离 + 条件单规范），本文件只管记录。**

## 前置：先读执行协议

每晚 23:20 / 23:40 预测跑完后，Agent 会用 `daily_order_plan.py <ticker>` 生成执行清单，写入当日文件的「📋 计划」区。
**你只负责照清单挂条件单，不在盘中改价。** 详见协议 §三「5 步流程」。

## 流程
1. 你发「准备」= 交易预案（标的 / 方向 / 计划价 / 计划仓位 / 触发理由 / 止损止盈）。
2. Agent 写入当日文件的「📋 计划」区，状态 = 计划中。
3. 你执行后发实际成交（价 / 量 / 时间），Agent 补「✅ 执行」区并回填计划，状态 = 已成交 / 已撤销。
4. 持仓变动同步更新 `positions.md`。

## 价位来源规则（2026-10-15 起）
| 场景 | 价位唯一来源 |
|---|---|
| TradingAgents 已出价格块 | `results/daily/<ticker>_<run_id>.json` 的 `trader_investment_plan` / `final_trade_decision` |
| 模型未覆盖的品种 | 手动，但必须在当日文件写明价位依据（技术位 / 消息 / 用户指令） |
| 无任何依据 | **不下单**，写「无数据」 |

严禁编造价位。缺口就写缺口。

## 单条字段
| 字段 | 说明 |
|------|------|
| 日期 | 计划日（YYYY-MM-DD） |
| 标的 | 代码 + 名称 |
| 方向 | 买入 / 加仓 / 卖出 / 减仓 / 清仓 |
| 计划价 | 准备时填 |
| 实际价 | 成交后填 |
| 数量 / 金额 | 股数 or 金额 |
| 仓位% | 占组合比例（变动后） |
| 触发理由 | 预测方向 / 技术位 / 基本面 |
| 止损 | 硬止损价 |
| 止盈 | 目标价 |
| QDII溢价校验 | 场内 QDII 必须填同日溢价：>5% 否决、≥3% 提示 |
| 状态 | 计划中 / 已成交 / 已撤销 |
| 备注 | 压力位 / 验证 / 偏离说明 |

## 纪律（与预测体系一致）
- 场内 QDII ETF 下单前必须填同日溢价；命中 >5% 红线**不得下单**（已有持仓不加仓）。
- 每条交易**先计划后执行**，不补造、不事后美化。
- 价位 / 仓位来自真实价格结构或你的指令，无证据写「未提供」，严禁编造。
- 重大事件日（美 CPI / LPR+GDP / FOMC）盘中不加仓（见各标的方案）。
- **止损 / 止盈 / 建仓一律用条件单**，触发价事前定好（协议 §二）。
- **金字塔仓位**：越买越低、越买越多；禁止两档等量（协议 §五）。
- **宏观外生冲击日**（CPI 超预期 / 鹰派 / 地缘 / 纳指单夜跌 >2%）：次日开盘前 30 分钟不建仓不加仓（协议 §六）。

## 操作依据强制规则（2026-10-16 约定）
> 西瓜枭明确：之后**每笔操作都会先告诉我**，由我把操作补进当日交易记录；**且每笔操作都必须带依据，无依据不记**。

- 你发「买了/卖了/减了/加了 XX」→ 我补进当日 `YYYY-MM-DD.md` 的「✅ 执行」栏（若无计划栏则新建），并同步 `positions.md`。
- **依据三选一必须有**：① 模型预测（`results/daily/<ticker>_<run_id>.json` 的价格块/评级）；② 已写明的纪律价位（止损/减仓梯/观察位/红线超限）；③ 你的明确指令（须原文记录）。
- 若你发来的操作**找不到依据**（没对应预测、不在纪律触发带、也没说指令）→ 我先**反问确认**，不擅自美化补依据、不编造。
- 已成交/已撤销都要回填状态，不事后补造计划。

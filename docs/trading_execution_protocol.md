# 交易执行协议（预测 → 决策 → 条件单）

> 目标：把 TradingAgents 的每日预测变成**可执行的挂单清单**，杜绝「盘中临时决策」。
> 首次落地：2026-10-15。触发事件：515220 当日亏损复盘。
> 配套：`trading_journal/README.md`（记录约定）、`docs/daily_mandatory_predictions.md`（预测产出）

---

## 一、分工边界：Agent 管决策，你只负责挂单

| 环节 | 谁做 | 说明 |
|---|---|---|
| 方向 / 价位 / 仓位 / 止损 / 止盈阶梯 | **TradingAgents + Agent** | 每晚 23:20 预测输出，Agent 审核后写成清单 |
| 挂条件单、填数量 | **你** | 只做机械执行，不做二次判断 |
| 盘中临时改价 | **不允许** | 改价 = 重新走一遍决策流程 |

**核心原则：决策和执行分离。盘中你不思考，只挂单。**

---

## 二、条件单的适用范围（你 10-15 问的问题，答案在这里）

### 必须用条件单的场景

| 场景 | 触发单类型 | 依据 |
|---|---|---|
| **止损** | 止损条件单（价格触发即市价/对手价） | 模型的 `stop_loss` / `invalidation_price` |
| **止盈减仓** | 限价条件单（到价即挂限价） | 模型的 `scale_out_ladder` 各档 |
| **建仓** | 限价条件单（到价才成交） | 模型的 `entry_zone` 下沿 |
| **加仓** | 限价条件单 | 模型的 `entry_zone` 上沿或阻力突破位 |

### 可以手动的情况（仅两种）

1. **补全信息后的首次建仓**：需要你确认股数 → 手动挂限价单，但价格必须来自清单，不得自行改动。
2. **模型未覆盖的品种**：TradingAgents 未出价格块 → 手动，但必须在 `trading_journal` 写明价位来源。

### 条件单解决不了的问题（重要）

条件单只保证「触发后不犹豫」，**不保证「触发前判断对」**。

2026-10-15 实测：全程条件单仍然亏 352 元 —— 因为三个错误全在挂单之前：
- 建仓价超出模型给的支撑带上沿（1.288 vs 1.282）
- 两档等量，没有金字塔加码能力
- 止损位虽然对（1.258 ≈ 模型 1.255），但**模型的技术止损位本身未覆盖外生宏观冲击**（CPI 超预期）

**所以顺序永远是：先改决策，再谈条件单。条件单是执行纪律，不是决策质量。**

## 三、每笔交易的标准流程（5 步）

```
第1步  前一晚读取 TradingAgents 预测（23:20 daily_predict → 23:40 cycle）
        ↓ 提取字段：Rating / Entry Price / Support / Resistance
        ↓           entry_zone / stop_loss / invalidation_price / scale_out_ladder
第2步  Agent 审核：与最新价结构对比，写入当日 trading_journal 的「📋 计划」区
        ↓ 标注：合规 / 否决 / 需补数据
第3步  你按清单挂条件单（不改价）
        ↓
第4步  触发即执行，事后不追单
        ↓
第5步  收盘后 Agent 复盘：执行 vs 清单偏差 → 写入「✅ 执行」区 + 更新 positions.md
```

**跳过第 1–2 步直接下单 = 违规**（10-15 的 1.288 那笔就是这个问题）。

```
  数量：___ 股（1/6 单位）

```

## 五、金字塔仓位规则（10-15 违反项）

**要求：越买越低、越买越多。**

| 档位 | 价格 | 数量比例 | 说明 |
|---|---|---|---|
| 首档 | 支撑带**上沿**（如 1.282） | 1/4 单位 | 先试仓 |
| 二档 | 支撑带**下沿**（如 1.272） | 1/3 单位 | 加码 |
| 三档 | 破下沿后的确认位 | 1/3 单位 | 仅在有承接时 |

**禁止**：两档同量、越买越轻、或未到支撑带就建仓。

**10-15 反例**：1.288 与 1.272 两笔**各 8000 股**，等量 ⇒ 只有单价暴露，没有摊薄能力。若只做 1.272 一笔，亏损减半。

## 六、宏观外生冲击的临时规则（10-15 新增）

TradingAgents 的 `stop_loss` / `invalidation_price` 基于价格结构 + 基本面，**不含隔夜宏观事件**。

**触发条件**（任一）：
- 隔夜美 CPI / PCE 超预期
- 美联储官员鹰派表态
- 地缘冲突升级（油价急涨）
- 单夜美股/纳指跌幅 > 2%

**处理规则**：
1. **次日开盘不建仓、不加仓**（至少前 30 分钟观望），无论价格是否在买区内。
2. 已持条件单的**不撤销**（让市场自己证明对错），但可考虑上移止损至更保守位。
3. 盘后可重新问 Agent 做一次事件后评估，再决定是否恢复原计划。

## 七、红线闸门（Agent 审核必过）

| 检查项 | 否决条件 |
|---|---|
| 场内 QDII 溢价 | >5% 一律否决下单；≥3% 必须提示 |
| 事件日 | 美 CPI / LPR+GDP / FOMC 当日盘中不加仓 |
| 追高 | 建仓价超出 `entry_zone` 上沿 = 否决 |
| 止损 | 无止损位的建仓 = 否决 |
| 仓位 | 单日新开仓 > 20% 总资产 = 否决 |
| 数据完整性 | 股数/成本/总资产任一缺失 → 判定结论降级为「不可核算」 |

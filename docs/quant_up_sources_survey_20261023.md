## 一、任务背景（复用本文档时必须带的上下文）

- **用户路线**：ETF 轮动 + 半自动化量化（只做筛股和回测，**不碰交易接口**）。
- **已有资产**：TradingAgents 预测 pipeline（morning_briefing.py + daily_predict.py，唯一有效路径 `E:\Trade\TradingAgents`），自选股池 21 只（含 7 只 A 股 ETF：512400 / 159611 / 510160 / 589720 / 159748 / 516090 / 512170）。
- **本次调研目标**：
  1. bilibili 及其他自媒体平台上，个人量化做得比较好、**有实盘数据**的 UP 主；
  2. 这些人里**有源码可供参考**的；
  3. 聚焦**筛股+回测型半自动化**（绕开接口监管）、**带源码**的人选。
- **明确排除**：GitHub 项目本身的年化数据横评（后续单独讨论）。

## 二、核心结论（TL;DR）

1. **B 站是量化教学的主阵地，不是实盘的主阵地。** 有长期可验证实盘的个人玩家集中在：公众号、雪球、东方财富/同花顺、集思录、淘股吧、且慢。
2. **实盘第一梯队 5 人**：云飞量化、海龟量化、远凡量化、yyb凌波、ETF拯救世界（E大）。**避雷 3 个**：持有封基（2026-05 已全网停更）、银行螺丝钉（十年年化仅 2.14%，口号注水）、邢不行/文俊de小迷妹（教学顶流但无系统实盘）。
3. **有实盘的人几乎没有源码；有源码的人几乎全是研究型**——这正好匹配"不碰接口"的路线。实盘主里代码公开度最高的邢不行是教学号，不是实盘号。
4. **半自动化推荐栈**：数据（qstock / akshare / tushare）→ 筛股（qstock 选股模块 + 邢不行因子实现）→ 回测（**DoriBT**，A 股交易规则内置）→ 信号输出（邮件/飞书/Excel）→ 手动执行。与现有 TradingAgents pipeline 并联，不冲突。
5. **监管信号**：2026 年起个人量化自动交易接口全面收紧（云飞量化平台已关闭自动交易接口、miniQMT 2026-09 被券商停用、QMT 限制外接策略）——半自动化是正确方向，执行层降级方案（条件单/半自动）要早想。

## 六、筛选核实标准（5 条，以后自己筛人时复用）

1. 实盘挂在**第三方可查的载体**上：同花顺投顾、东财财富号、雪球、淘股吧实盘比赛、且慢跟投记录——不是微信群截图；
2. 日更连续 **2 年以上**，穿越至少一轮完整牛熊；
3. **敢公开亏损和回撤**（云飞公开 -19.25%、海龟公开 2026 年 -9.82%，是加分项不是黑点）；
4. 警惕**卖课/拉群/知识星球**——利益结构决定话术；
5. 小市值、可转债类策略有**容量上限**，大资金跟投即失效。

## 七、对口建议与推荐工作流

**推荐工作流（绕开接口监管，与现有 pipeline 并联）：**

```
数据层：qstock / akshare / tushare
   ↓
筛股层：qstock 选股模块 + 邢不行的因子实现
   ↓
回测层：DoriBT（A 股佣金/印花税/涨跌停/复权规则内置，不用自己对账）
   ↓
信号层：每日信号输出（邮件 / 飞书 / Excel）
   ↓
执行层：手动执行（不碰交易接口）
```

- 系统底座参考 **Mr.看海 OSkhQuant**（GUI+本地数据+可视化回测，开箱即用）；
- 回测层换 **DoriBT**（省掉交易规则核账的苦活）；
- 选股信号层抄 **qstock 和邢不行的因子代码**；
- 实盘纪律与展示格式参考 **云飞量化**（日更框架）和 **远凡量化**（淘股吧比赛公证机制，可直接抄来用在自己的实盘展示上）；
- AI+量化架构思路参考 **交易回战的 B 站免费视频**（双账户模拟 vs 实盘比对、记忆系统、规则风控与 AI 决策分离）——星球不必进。

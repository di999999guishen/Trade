# 可直接使用的模块开发提示词

用法：先发送P00，再按路线发送对应模块提示词。每个提示词都要求交付代码和真实验证，不能用口头计划冒充完成。**这些提示词是给后续开发使用，本次交付不代表其中模块已经实现。**

当前根目录为 `E:\Trade\TradingAgents`；方案位于 `docs/quant_research/`。实现前读取当时有效的AGENTS.md与git状态，保护用户已有修改。各模块以本目录设计为默认；发现工具版本或数据不支持时先做兼容性验证，并记录具体差异。

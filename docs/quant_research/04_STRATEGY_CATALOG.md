# 美股量化策略研发目录

版本：2026-09-17。状态：研究规格，尚未运行这些策略、取得策略收益或完成样本外验证。

本目录按“先免费 ETF 日线做多，验证流程后再购买必要数据”的顺序安排。日频是每天计算和检查目标仓位，不要求每天成交。默认不加杠杆；允许做空、期权并不意味着第一阶段需要使用它们。所有参数是预先登记的研究起点或验收门槛，不是已测得的最优参数、收益承诺或当前交易建议。

## 1. 开发顺序与策略定位

| ID | 策略 | 数据和开发阶段 | 主要研究问题 | 简单对照 |
|---|---|---|---|---|
| S1 | ETF 趋势过滤 + 相对动量轮动 | P0，免费日线先做 | 趋势过滤能否改善回撤，轮动是否有扣费后增益 | 买入持有、固定池等权、单一 200 日均线 |
| S2 | ETF 多因子 + 风险预算 | P0/P1，免费日线 | 分散和风险预算能否提高组合稳定性 | S1、无预测等权、仅逆波动 |
| S3 | ETF LightGBM 横截面排序 | P1，免费日线谨慎研究 | 小截面的机器学习是否优于简单规则 | S1/S2、线性模型、单动量 |
| S4 | 股票质量 + 盈利能力 + 动量 | P3 扩展，PIT 股票池和财务数据 | 能否在受控行业和规模暴露下增强指数 | 同池市值加权、单动量、单质量 |
| S5 | 财报后漂移 PEAD | P3 扩展，PIT 财报实际值/预期/发布时间 | 财报意外信息在可成交时点后是否仍有效 | 同池随机事件、单盈利意外 |
| S6 | ETF 残差反转多空 | P3 扩展，历史借券与更细成交数据 | 扣除交易和借券成本后是否有独立收益 | 原始反转、残差但不设择时门槛 |
| S7 | ETF 期权保护与覆盖 | P3，付费历史期权数据 | 是否按预定成本降低尾部损失或调整收益分布 | 无期权原组合、减少股票仓位 |
| S8 | RD-Agent / 符号因子挖掘 + 集成 | P3，前述验证体系成熟后 | 自动提出的新因子能否在独立留出集增加净收益 | 固定规则因子库、S3、随机表达式 |

前三套先在 Qlib 研究环境中完成；P2 专门完成 LEAN raw 独立复核和前瞻观察，通过后再进入 P3 的股票、事件、做空、期权和自动挖掘扩展。通过研究的同一份冻结信号/目标权重文件交给 LEAN 本地源码引擎复核；禁止两边各写一份策略逻辑，然后仅比较最终收益。期权执行需分钟级报价事件，属于日频决策的执行例外。

## 2. 所有策略共同遵守的研究约定

### 2.1 ETF 池、时点与数据范围

初始固定池共 18 只：

```text
宽基：SPY QQQ IWM MDY
行业：XLB XLE XLF XLI XLK XLP XLU XLV XLY XLRE XLC
分散资产：IEF TLT GLD
```

该池在 2026-09-17 选定，代表方便开发的覆盖面，具有事后选池和存续偏差；不能将其结果称为完整历史 ETF 市场的无偏收益。每只 ETF 只有在当时已上市、有有效行情且完成至少 **253 个有效收盘价格点**的预热后才进入可选池。计算 `P_t/P_(t-252)` 需要这 253 个观测，程序须按最长滞后加 1 检查，不能只要求 252 行。不把 XLC、XLRE 等后成立基金的行情向历史回填，不用当前热门股票替代历史股票池，不用合成价格冒充真实可交易历史。正式扩大 ETF 市场研究时，应增加已清盘 ETF、历史基金主数据及可得时点。

| 项目 | 统一规则 |
|---|---|
| 决策时刻 | 每个美国交易日 `18:00 America/New_York`，按当地夏令时计算 |
| 信息截点 | 每条输入必须满足 `available_at <= decision_time`；18:00 前没有发布/到达的输入顺延 |
| 最早成交 | 下一交易日正常交易时段开盘；期权 S7 单独推迟到 09:45 |
| 收盘行情 | 仅使用已完成并已到达的日线；迟到、修订和异常数据保留版本 |
| 盘前新消息 | 不偷偷加入昨日信号；留到下一次 18:00 决策，除预先写定的执行取消规则 |
| 调仓频率 | 每日计算；通常单标的目标权重变化达到 2 个百分点才提交调整，退出/风险规则优先 |
| P0/P1 权重执行代理 | 冻结前一日信号后，可按次日复权 open 理想化配置目标权重，使用归一化分数单位并计入总摩擦；须披露精确配权和成交近似，不得导出为真实订单 |
| P2 开盘订单数量 | 用决策时已知 NAV、上一日已知价格和可用现金计算真实股数并预留费用；不可倒用次日开盘价“提前”算出恰好满仓的订单 |
| P2 买入资金不足 | 开盘跳空或卖单未成交导致不足时，缩量/拒单并记录；不自动融资 |
| ADV | `ADV20_t = mean(raw_close_s * raw_volume_s, s=t-19..t)`；仅用决策前已完整的日线 |
| ETF 流动性入池 | 原型默认已核验 `ADV20_t >= 10,000,000 USD`；策略可预登记更严格门槛，缺少可核验价格量时标记不满足条件 |
| 订单容量 | 原型单只订单金额不超过已知 `ADV20_t` 的 1%；这不证明开盘时真的有足够流动性，正式验证需成交时段数据 |
| 缺失数据 | 不插值出可交易价；暂停新增仓位，按预登记的停牌、退市及清盘规则处理旧仓 |

P0/P1 Qlib 默认 `adjusted_total_return_proxy`：同一个调整因子作用于 OHLC，持仓是归一化分数单位，含分红收益近似已体现在价格中；**不另加现金股利、不因拆股再调整持仓单位**。P0 只输出信号和目标权重，其份额不是历史真实股数，不应送到券商。S1/S2 可用次日复权开盘价实现理想化配权，报告须写明分红再投资、支付时点和成交代理的局限。

P2 `raw_with_corporate_actions` 才使用未复权可交易价格、真实股数及独立公司行动账本：拆股改变股数，除息确认应收，支付日转入现金。信号可用截至当时构造的连续收益链；成交账本不得同时使用复权收益又追加分红/拆股。两种模式不能混合到同一曲线。当前下载的静态后复权历史不等于历史每一天可获取的数据快照，免费阶段保留此限制并冻结原始下载文件。ADV 和绝对价格过滤始终使用相应时点已核验的价格量，不能把复权价与不匹配的量相乘。

S1/S2 默认采用单日调仓软上限 `turnover_including_cash = 0.5 * sum(abs(w_target - w_current)) <= 0.20`，求和包含现金，`w_current` 为决策时点按统一估值所得权重。先满足强制退出/降险，再将可选调整按同一比例缩小至剩余预算，未达到最终目标的部分下一交易日重新计算，禁止预先承诺使用未来信号分期交易。强制降险可超过软上限，但必须记录原因、豁免额和实际成交；2 个百分点的成交门槛不应阻止强制退出。报表另列传统不含现金的 `0.5 * sum(abs(delta_weight_assets))`，不能与含现金指标混称。费用始终直接按每笔实际买卖名义金额计算，不能从任何一种换手率再推测乘 1 倍还是 2 倍。

### 2.2 成本与基准

P0/P1 免费原型使用 **5 bps 单边 all-in 总交易摩擦假设**，同时运行 **10 和 25 bps 单边压力情景**。每笔买、卖各按执行名义金额的绝对值计算一次：`cost = abs(executed_notional) * bps / 10000`。此假设合并佣金、价差和冲击等交易摩擦，**separate fee = 0**，不能再加一层佣金或滑点。它是统一研究预算，不是经核实的券商报价。

P2 raw 执行阶段才拆分实际佣金、交易费、价差、冲击及适用的借券/融资费用；拆分模型替换研究用 all-in 交易成本，不能叠加收费。借券和融资属于 S6 等专用策略的持有成本，另行建模并明确假设。所有结果同时报告毛收益、净收益、换手及成本损耗。[AQR 的交易成本研究](https://www.aqr.com/insights/research/working-paper/trading-costs)支持将成本和规模纳入研究，但本项目的 5/10/25 bps 是情景假设，未由其论文校准。

SPY 和 QQQ 分开报告含分红再投资的总收益买入持有基准，使用与策略相同的 `price_mode`、样本起止日、资金投入日、计价货币和费用口径。P0 双方均用总回报代理且不重复入账分红；P2 双方均使用独立公司行动账本。首次建仓费用计入；不平仓结束的结果对双方均只估值，若增加期末清算结果则双方同样处理。不能用价格指数对比策略的含分红收益，也不能事后只挑更容易战胜的指数。初始现金收益为 0；任何基准中的现金也为 0。以后加入实际可得的短债/现金收益序列时，全部策略和对照统一重跑，并报告税前口径。

“跑赢”至少分成三项，禁止互换表述：

1. **绝对超额**：净累计收益和 CAGR 是否分别高于 SPY、QQQ。
2. **风险调整改善**：Sharpe、Sortino、Calmar、最大回撤与尾部损失是否改善。
3. **暴露调整后的收益**：市场 beta、行业/风格暴露、跟踪误差和回归 alpha 是否支持独立贡献。

低回撤策略可能长期跑输 QQQ 的绝对收益；这只能写成风险改善。信息比率分别用策略相对 SPY 和 QQQ 的日收益差计算。alpha 使用可解释的因子暴露及稳健误差估计；Ken French 因子下载序列可作事后归因，不直接假设其全部历史值在当时已发布可用于实时交易。[Ken French 官方数据说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)

### 2.3 共同的证据与晋级门槛

以下门槛是项目治理选择，不代表达到门槛就能证明未来盈利。

- 完成数据时点、公司行动、标签重叠、费用和逐笔现金账本检查。相同输入运行两次，信号和成交计划哈希一致。
- 时间切分，不随机打散；推荐至少 5 年训练、1 年验证、1 年滚动测试，历史不足时标为流程演示而非有效性结论。ETF 规则策略不必机械训练模型，但任何参数选择仍只能使用开发区间。
- 标签跨度内的样本跨越训练/验证或测试边界时删除，按事件区间做 purge；设置与最长标签持有期一致的保守间隔。将重叠持仓和日期共同冲击计入统计误差，不能把每个“ETF × 日期”都当作独立样本。
- 在首次研究前锁定最近完整、可用且尚未查看结果的 24 个月作为最终留出集；如已据此改过策略，它就是开发集，重新登记未来前瞻期。留出集只对冻结后的候选运行一次，失败后不得继续调整并沿用“独立样本外”标签。
- 建议至少 3 段滚动样本外、合计 36 个月以上的研究证据，并有与策略目的相关的上涨、快速下跌、震荡或利率冲击环境。最终留出另列；证据不足时继续观察。
- 对净超额收益使用按日期分块的 bootstrap/HAC 等方法给出置信区间；展示所有尝试次数、参数组合、被淘汰方案。自动挖掘增加 DSR 等多重试验诊断，不把 DSR 数字解读为未来赚钱概率。[DSR 原始论文](https://doi.org/10.2139/ssrn.2460551)
- 工程验收和投资假设验收分开：程序可正确运行而策略假设失败，仍是有效研发结论。通过回测后建议至少 60 个交易日纸面运行验证时间/费用/对账，不能据此宣布长期 alpha 已证实。

## 3. S1：ETF 趋势过滤 + 相对动量轮动

**定位和优先级：** 第一套应落地的完整策略。先建立可信交易账本及风险基线，再判断轮动是否增加收益。趋势研究提供经济假设，不能把多资产期货的论文收益直接搬到本 ETF 做多方案。[AQR：A Century of Evidence on Trend-Following Investing](https://www.aqr.com/-/media/AQR/Documents/Insights/Journal-Article/AQR-JPM-Fall-2017.pdf)

**股票池/数据：** 上述固定 18 ETF，可用历史日线、调整因子和公司行动原始记录；至少 253 个有效收盘价格点预热。P0 使用统一复权 OHLC 总回报代理，不重复进行分红/拆股份额入账。原型不需要基本面、新闻、LLM 或期权。

**特征和信号：** 令 `P_t` 为统一口径的收盘总回报序列：P0 为 `adjusted_total_return_proxy`，P2 为截至 t 可知的公司行动构造的收益链。`R_h=P_t/P_(t-h)-1`，`MA200=mean(P_(t-199)..P_t)`。

```text
eligible_i = 有效行情 且 P_i,t > MA200_i,t 且 R_126,i,t > 0
score_i    = 0.5 * R_126,i,t + 0.5 * R_252,i,t
selected   = eligible 中 score 最高的 5 只；并列按固定 symbol 排序
raw_weight = 每只 selected 分配 20%；不足 5 只的余额为现金
```

18:00 冻结信号，下一交易日开盘最早成交；趋势退出目标为 0，优先于 2 个百分点换手门槛。保留完整排名以检查门槛附近的换手。选择后的仓位限制只向下缩减，不重新寻找“更好”ETF 补满现金。

**持仓与风控：** 单只不超过 25%；总多头不超过 100%；`QQQ+XLK+XLC <= 50%`；11 只行业 ETF 合计不超过 60%。依次按组内同比例缩减至上限，再保留现金。它们只是重复敞口代理，不能替代 PIT ETF 持仓穿透。不能把 SPY、QQQ、XLK 同时持有描述为充分分散。对短期回撤不添加未经预登记优化的止损曲线。

**成本与基准：** P0 使用共同 5/10/25 bps all-in 摩擦，separate fee 为 0；P2 改用拆分成本模型。必报 SPY TR、QQQ TR；另外对比同一个按上市时点过滤的固定池等权组合，等权每月末调整、每只最多 25%、缺额现金。再加“只持 SPY，跌破 MA200 退出现金”的单规则对照，分清轮动与择时的贡献。

**失败环境：** 快速 V 型反弹、无趋势震荡会反复进出；长期单边科技牛市容易落后 QQQ；股债同时下跌时 IEF/TLT 不一定起保护作用；QQQ 和行业基金的重叠会放大主题暴露。

**最少样本证据与验收：** 可得部分尽量覆盖至少 10 年并单列历史资产数；至少 36 个月滚动样本外、最终 24 个月留出和至少 100 次实际调仓事件作为流程观察规模，不把事件视为独立统计样本。若净绝对超额不成立但最大回撤较 SPY 降低至少 20% 且 Calmar 提高，可归为“防守候选”，不能归为“指数超额候选”。删除任何一个单一 ETF、将决策额外延迟一天及使用 10 bps 成本后若结论反转，报告脆弱性；25 bps 为极端压力披露。

## 4. S2：ETF 多因子 + 风险预算

**定位和数据：** 第二套先做的 ETF 日频策略。仍用 18 ETF；目标是让预测得分、波动和相关性同时进入权重，不把“多因子”理解成增加很多复杂特征。

**特征公式：** 使用同一收益链及当时有效横截面内的百分位排序 `rank_pct`，范围 `[0,1]`。

```text
mom_12_1 = P_(t-21) / P_(t-252) - 1
mom_6_1  = P_(t-21) / P_(t-126) - 1
vol_63   = std(log(P_s/P_(s-1)), s=t-62..t) * sqrt(252)
down_63  = sqrt(mean(min(r_s, 0)^2)) * sqrt(252)
score    = 0.45*rank_pct(mom_12_1)
         + 0.25*rank_pct(mom_6_1)
         + 0.15*rank_pct(-vol_63)
         + 0.15*rank_pct(-down_63)
eligible = P_t > MA200 且 mom_6_1 > 0
```

取可选集合得分最高的 8 只。先构造 `a_i=(0.5+score_i)/max(vol_63,i,0.05)`，归一化得到风险预算参考权重。对组内上限和单只 25% 上限依次缩减，余额保留现金，不借钱补足。

**相关性约束和波动缩放：** 用过去 126 日收益估计日协方差，采用预设收缩 `Sigma=0.7*sample_cov+0.3*diag(sample_cov)`；不得挑选样本外表现最好的收缩系数。`sigma_p=sqrt(252*w' Sigma w)`，最终 `w=w*min(1,0.10/sigma_p)`。10% 是研究波动目标，无法保证未来波动或回撤上限。若样本协方差不可用，保持现金，不能填入未来估计。

**时点/频率/持仓：** 每日 18:00 决策，次日开盘，权重偏差达到 2 个百分点才交易。沿用 S1 的 `QQQ+XLK+XLC` 和行业 ETF 总额约束。额外保存股类、债类、黄金的预算、过去相关性、预测波动和实现波动；风险预算使用过去估计，不能暗示永远防守有效。

**成本与对照：** P0 为 5/10/25 bps all-in 摩擦且 separate fee 为 0，SPY TR 与 QQQ TR 分别比较；最重要的消融是“仅逆波动无预测”“仅多因子等权”“完整 S2”。再比较与 S2 相同波动目标的 SPY/QQQ 加现金对照，才能判断改善是否仅来自降低股票仓位。波动目标对照同样只能降仓、不加杠杆。

**失败环境：** 相关性突然跳升，长债与股票共同下跌，低波动资产突然破位；缓慢趋势组合的信号重复，新增因子可能只是重复计算动量。成本门槛太小会把估计噪声变成换手。

**最少样本证据与验收：** 和 S1 相同历史要求；至少 36 个月滚动样本外，覆盖一次利率/相关性冲击。预测波动与实现波动对照可解释，风险贡献和组内上限逐日可核对。默认晋级标准为净 Sharpe 较 S1 提升至少 0.10，且最大回撤没有恶化；若只胜过未匹配风险的 SPY，不能称为预测增益。即使达到门槛，也需报告统计区间与留出结果。

## 5. S3：ETF LightGBM 横截面排序 / Alpha158 美股适配

**定位：** 先验证机器学习能否在 18 ETF 的小截面中贡献增益。日样本很多但独立资产和市场状态很少，不能把数据行数作为大样本证明。若免费阶段没有优于规则，不继续堆模型；需要扩展到 PIT 股票池时再进入付费阶段。

**输入：** 先用不超过 20 个透明价量特征：`R_5/R_21/R_63/R_126`、`mom_12_1`、`P/MA20-1`、`P/MA60-1`、20/63 日波动、20 日下行波动、20/60 日最大回撤、日内振幅、`(close-open)/open`、`volume/mean(volume_20)`、20 日价量相关性等。所有窗口均在 t 收盘结束。

第二轮再接入 Qlib Alpha158 的可用特征子集。官方实现含 K 线结构、价格比例及滚动价量特征，默认还涉及 VWAP；免费 OHLCV 没有真实日内 VWAP 时禁用该特征，禁止拿 `(H+L+C)/3` 冒充成交量加权均价。结果命名为 `Alpha158-US-ETF-reduced`，保存实际特征数量和表达式。[微软 Qlib 官方特征实现](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)

**目标标签与模型：**

```text
y_i,t,h = TR_close_i,(t+h) / TR_open_i,(t+1) - 1
h = 5  # 20 日为另行登记的研究变体
```

统一标签区间为 `open[t+1] → close[t+h]`：t 日 18:00 决策，5 日标签从 t+1 开盘到 t+5 收盘；h=1 即次日开盘到次日收盘。P0 使用相同调整因子的 open/close 总回报代理，不再追加现金股利或拆股份额；P2 使用 raw 入场及公司行动一致的期末财富计算相同区间收益。标签在退出收盘价实际可得后才成熟。未来信息只能进入标签，不能进入特征、归一化或当时股票池。标签模型用于每日更新目标权重，真实组合因每日调仓产生的持有期仍以账本为准。

Qlib 官方 Alpha158 的默认标签基于未来收盘价，和本项目执行约定不同，必须显式覆盖，不能直接复制示例配置。[Qlib 官方 handler 与默认标签](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/handler.py)

先训练 LightGBM 回归，再按预测值排序；这也是横截面排序策略，不要求第一版使用 LambdaRank。预设起点：`num_leaves=7, max_depth=3, learning_rate=0.03, min_data_in_leaf=200`，最大 500 棵树，验证集早停。最多登记 12 个参数组合。归一化、截尾、缺失值处理参数只在训练窗口拟合；全横截面同一时点已知的排序变换可以使用当时可选 ETF，但不跨越日期拟合。

**训练和持仓：** 使用 5 年训练 + 1 年验证 + 后续 1 年测试，季度重训；每次训练只能见到已成熟的标签，边界按 `[open(t+1),close(t+h)]` 删除重叠样本，并留与最长标签跨度一致的保守间隔；h=5 的起点为 5 个交易日。每日 18:00 预测，次日开盘最早执行。在满足 S1 趋势门槛的 ETF 中选预测最高的 5 只，每只 20%，缺额现金，沿用 S1 集中上限与 2 个百分点成交门槛。对“无趋势过滤”的变体单独登记，不能看过留出结果后再选择。

**成本/基准/失败环境：** P0/P1 为 5/10/25 bps all-in 摩擦、separate fee 为 0；SPY TR、QQQ TR、S1、S2、Ridge 回归和单动量为对照。市场制度切换、资产高度共线、样本只有少数资产、过多超参以及隐含债券/股票身份捷径，都可能让样本内模型漂亮而样本外无效。不得照搬 Qlib 的中国市场涨跌停、基准、费率和交易限制。

**最少样本证据与验收：** 至少 3 个完整滚动测试年度及独立 24 个月留出；逐日 RankIC 和置信区间只是诊断，8/18 个相关 ETF 的横截面 IC 不能单独过关。净收益、Sharpe、成本后增益必须在相同仓位约束下胜过最佳简单基线；建议以多数滚动区间正增益、净 Sharpe 增量至少 0.10、10 bps 下不反转为晋级门槛。对扩大至股票的版本，重新登记 PIT universe、行业中性、停牌退市和标签规则，不能继承 ETF 阶段结论。

## 6. S4：股票质量、盈利能力与动量增强

**前置数据和池：** P3 付费或经过完整历史重建的数据扩展，复用 P2 已验证的 raw 引擎；每月末用当时已知的美国普通股主数据，筛选价格大于 5 美元、过去 20 日平均美元成交额大于 2,000 万美元、具有至少 253 个有效价格点，并按当时市值取前 1,000 只。保留后续退市、并购、代码变更的证券 ID。此阈值为预设流动性过滤，金额随研究资金规模复核。不能拿今天的 S&P 500 成分向过去回测。

**PIT 财务特征：** 只读取当时已公开版本，记录 `period_end / filed_at / published_at / available_at / revision_id`。财报期末日期不等于发布日期。SEC 免费接口提供提交及 XBRL 数据，可用于构建原始证据，但仍需自行重建版本、标签映射和历史可得时点，不能直接把最新 company facts 当作 PIT 面板。[SEC 官方 API 说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

令 `A` 为期初期末资产平均值，分母要求为正：

```text
gross_profitability = gross_profit_TTM / A
cash_profitability  = cash_flow_from_operations_TTM / A
accruals            = (net_income_TTM - cash_flow_from_operations_TTM) / A
leverage            = total_debt / total_assets
quality             = mean(z(gross_profitability), z(cash_profitability),
                           z(-accruals), z(-leverage))
momentum            = P_(t-21)/P_(t-252)-1
score               = 0.5*z(quality) + 0.5*z(momentum)
```

`z` 为当时行业内 2.5%/97.5% 截尾后标准化。若某行业不足 20 个有效样本，则按预登记规则退回全池标准化并标记；财务字段缺失不凭模型填成“高质量”，剔除并报告覆盖率。首版剔除银行、保险等财务结构难以直接比较的行业；另做包含金融的专用定义后才能扩展。

**构建/时点：** 每日 18:00 更新价格特征，有新财报且已到达才更新财务；每周最后交易日生成调仓目标，次日开盘成交，日常每日只做数据与风险检查。分数前 100 只等权，单只不超过 2%，行业权重相对同池基准偏离不超过 5 个百分点。第一版约束削减后剩余现金，或由明确优化器求解，不通过未知未来收益补位。

**依据及对照：** 盈利能力和质量因子有原始研究与公开因子数据支持，但这里的组合及多头约束是新研究规格，不是复现论文的多空收益。[AQR Quality Minus Junk](https://www.aqr.com/Insights/Datasets/Quality-Minus-Junk-Factors-Daily)。同时报告 SPY TR、QQQ TR、同一历史股票池市值加权及单动量/单质量对照，剥离小盘和行业偏离。

**成本/失败环境/验收：** 研究可先用 5/10/25 bps all-in 场景，正式 raw 结论替换为规模、价差和流动性校准的拆分成本；两者不叠加，5 bps 不能无条件当作所有股票真实成本。质量股估值压缩、低质量股票暴涨、动量崩溃及行业定义错误均可能失效。建议至少 10 年历史、3 年滚动样本外及 24 个月留出，覆盖 200 只以上当时有效股票；至少比较 100 个分散调仓日期。只有在成本后相对 SPY 的绝对超额、行业/规模调整和多数滚动区间一致时，才列为 SPY 增强候选；对 QQQ 单独给出结论。

## 7. S5：财报后漂移 PEAD

**前置数据：** 沿用 S4 流动性股票池，但需要事件级实际 EPS、相同会计口径的历史分析师预期、预期快照时间、首次财报发布时间、修订时间、时区和供应商到达时间。必须区分 GAAP/非 GAAP、季度/年度、持续经营项目、拆股后的每股口径。缺少 PIT 预期和发布时间时，本策略不具备有效回测条件；仅用 SEC 实际值不等于复现分析师盈利意外策略。

**信号公式：** 在事件发布时间前至少 60 分钟冻结最后一份可得预期快照，`err_q=actual_EPS_q-median_estimate_q`。将历史误差统一到本次每股口径；过去 8 个已发布季度至少有 6 个有效误差：

```text
SUE_q = err_q / max(std(err_(q-8)..err_(q-1)), 0.01 USD/share)
```

0.01 美元只是防零分母的研究地板，要随拆股口径调整并做灵敏度披露。若无合格历史或预期冻结证据，则跳过。用事件发生前 252 个交易日同类事件的 SUE 分布，计算当前事件的历史百分位；不要求同一天凑齐横截面，也不借用未来事件的分布。

**时点和持仓：** 只有 18:00 前已发布、已到达并完成解析的事件，才能在下一交易日开盘建仓；18:00 后或次日盘前事件延至下一次 18:00 决策后执行。先研究正向意外位于历史前 20% 的多头，持有 20 个交易日，在预定开盘退出；出现新财报、交易停止等依预登记规则处理。并发单只最多 2%、行业最多 25%、总多头最多 100%，按事件 SUE 排序分配空闲资金；当日事件不足时保留现金。

**成本与对照：** 财报日跳空由真实次日开盘体现，不能假设在发布前收盘价买入。5/10/25 bps all-in 只是初步场景；正式 raw 回测应替换为事件日开盘价差、冲击和实际费用的拆分模型，排除无法成交的事件，不能在 all-in 上重复追加相同费用。必报 SPY TR、QQQ TR、同池基准和在相同日期/行业/流动性匹配的随机事件组合；比较无需预期数据的简单价格动量，验证昂贵事件数据是否提供额外价值。

**研究依据/失败环境：** 早期研究记录价格和盈利动量，支持“信息逐步反映”的假说；不意味着今日、液态大盘股、开盘后仍有同等机会。[Chan、Jegadeesh、Lakonishok 原始研究](https://www.nber.org/papers/w5375)。迅速价格发现、盘前跳空已吸收消息、预期口径不一致、异常值和事件成本可能消灭增益。

**最少证据与验收：** 至少 5 年事件历史、500 个合格事件、3 年滚动样本外，按财报日期和证券聚类评估误差；其中至少 200 个事件进入样本外持仓，不能把重叠持有期逐日当作独立收益。独立留出需满足共同要求，否则仅列探索。增加一天延迟、剔除最大盈利 10 个事件、翻倍事件成本后仍有一致方向的净增益，才考虑继续。默认不以空头负盈利意外替代多头失败的结果。

## 8. S6：ETF 残差短期反转多空

**定位：** 后续独立研究。优先在 ETF 上验证，不急于扩展到更昂贵、更难借的个股。短期反转是对交易成本非常敏感的假说；AQR 的研究展示了短期信号如何被换手成本吞噬，不能只看毛收益。[AQR：短期信号与交易成本](https://www.aqr.com/Insights/Research/Journal-Article/To-Trade-or-Not-to-Trade-Informed-Trading-With-Short-Term-Signals-for-LongTerm-Investors)

**数据/池：** 从 11 个行业 ETF 加 QQQ、IWM、MDY 中，选择当时满足上市预热、ADV20 超过 2,000 万美元且可借券的证券。需要历史 borrow availability、borrow rate、召回、替代支付分红及保证金规则。没有历史借券只能生成“假设可借”研究，不能称可执行策略。

**信号：** 对每只 ETF 用截至 `t-5` 的最近 126 日收益拟合 `r_i = alpha_i + beta_i*r_SPY + gamma_i*r_IEF + residual_i`；冻结系数后对 `t-4..t` 五日计算残差。`reversal_i=-sum(residual_i,5)/max(std(training_residual)*sqrt(5),epsilon)`。市场和利率因子是研究选择，需对仅 SPY 的简单残差作消融。

**时点和构建：** 每日 18:00 计算，次日开盘；若可借，最高分 3 只做多、最低分 3 只做空，初始各绝对权重 10%，毛敞口上限 60%。优化器只为满足净敞口绝对值不超过 2%、历史估计 SPY beta 暴露绝对值不超过 0.05、单只绝对权重不超过 10%；无可行解则减少仓位/现金，不提高毛敞口。信号不再位于入选集合时，次日开盘退出，最长持有 5 个交易日。借券被拒或召回按真实事件强制修正，并记录对冲误差。

**成本/现金：** P3 正式执行模拟复用 raw 引擎并扩展借券/保证金模块，采用拆分的交易成本，并独立入账真实借券费、替代分红、融资与保证金费用。若做研究敏感性，可用 5/10/25 bps all-in 替换交易成本部分，但不能与拆分的佣金、价差和冲击叠加。历史借券数据缺失时可做 2%/5%/10% 年化借券费敏感性场景，但只能是假设。卖空所得不是可再次无成本投资的额外权益；现金抵押、短仓负债与保证金按账本处理。

**基准/失败环境/验收：** SPY TR、QQQ TR 仍列出，但主要看净收益相对同口径现金、市场 beta 和对 S1/S2 的组合增益；中性策略不要求与 QQQ 同样风险预算下比绝对收益。比较原始五日反转与残差反转、零借券成本与真实借券成本。强趋势、主题结构变化、ETF 资金流持续性和开盘反弹已经发生都可能失效。至少 5 年日线、3 年滚动样本外、200 个以上有实际可借证明的入场日期，独立留出及成本压力后净收益仍为正才晋级。毛盈利、净亏损直接判为假设未通过。

## 9. S7：ETF 期权保护与覆盖

**定位：** 改变尾部风险和收益分布的扩展，不预设比买入持有或减仓更赚钱。第一版只选择 SPY 或 QQQ 中一个对应已持有 ETF 的子组合，避免多标的、动态择时和多腿优化同时展开。

**不可省略的数据：** 每个历史时点存在的完整期权链、合约 ID/乘数/交割调整、到期和行权方式、逐时点 bid/ask/NBBO、报价时间及有效性、历史 IV/Greeks 或仅用当时信息计算它们的模型、利率、已知分红、成交/持仓量可得时间、除息日、行权和指派事件。当前免费的期权链快照不能恢复过去多年链历史。没有这些数据时只实现接口、盈亏函数与到期场景，不输出历史策略收益。

**三种分别登记的实验：**

| 变体 | 决策规则 | 研究目的及主要代价 |
|---|---|---|
| S7-A Protective collar | 持有 ETF；买入约 -0.25 delta put，卖出约 +0.25 delta call，同到期，30–60 天中距 45 天最近的到期日 | 减少下行同时封顶上涨，净权利金未必为零 |
| S7-B Put debit spread | 持有 ETF；买入约 -0.30 delta put，卖出同到期约 -0.10 delta put | 限定保护成本；跌破低行权价后保护收益封顶，不能称全额保险 |
| S7-C Covered call | 对已有的可交割 ETF 股数卖出约 +0.25 delta call | 收取权利金、牺牲上行，仍保留大部分 ETF 下跌风险 |

Delta 来源必须是当时快照；若按价格计算，使用同一时点输入并保存模型版本。标准合约通常为 100 股，但实现必须读取实际乘数和调整后 deliverable，不硬编码所有合约都可用 100 股交割。short call 始终由实际持股完全覆盖；不使用裸卖期权。put spread 两腿必须按组合执行约定或处理单腿成交风险，不能假设永远同时成交。

**决策/成交/滚动：** 18:00 使用当日有效链快照选择合约，下一交易日 09:45 后才按有效同步报价提交限价/组合单；不使用日线 open 代表某个合约的真实可成交价。初始研究过滤为报价年龄不超过 30 秒、`bid > 0`、`ask >= bid`，且每腿 `ask-bid <= min(0.25 USD, 10%*mid)`；多腿报价时间相差不超过 5 秒，缺少对应粒度的数据即无法验证该规则。09:45–10:00 无合格报价则取消当日新增，不追价。不满足这些条件的强制平仓应按可得报价及压力滑点执行并标记，不能因报价过滤而假装永远无需平仓。每交易日检查；剩余期限降至 14 日时，在当日决策后安排下一日滚动，旧腿先按明确执行规则平仓，避免隐含裸仓。

**风控和费用：** 保护腿数量不得超过相应 ETF 覆盖数量；权利金、每合约费用、交易所费及成交价差分别入账；标的 ETF 仍遵守总资金约束。首版全组合现金预留至少 5%，每次新增净保护权利金上限为 NAV 的 0.5%，不够覆盖全部 ETF 时仅保护可承担部分，并报告实际覆盖率。权利金上限是买入门槛，不限制随后损失或强制平仓成本。禁止用全部 mid price 成交，至少提供买 ask/卖 bid 的保守情景及分腿部分成交情景。组合 dollar delta 除以 NAV 控制在 `[0,1]`，每日报告 gamma/vega 及标的 ±10% 和 IV ±10 个百分点的情景损益；保证金、指派现金需求及更严格风险限额在实验前冻结。发生指派后必须先对账再下新单。

**美式期权与除息：** 回测必须包含提前行权、提前指派、除息影响、到期自动行权、股数/现金变化及指派后的再平衡。[OIC 官方指派说明](https://www.optionseducation.org/referencelibrary/faq/options-assignment)说明美式期权卖方可能在到期前被指派。LEAN 支持 assignment model，但其默认规则是近似机制，不能自动视为已正确建模每次除息前指派；需要针对所用券商与合约验证并做压力场景。[LEAN 官方 assignment 文档](https://www.quantconnect.com/docs/v2/writing-algorithms/reality-modeling/options-models/assignment)

**对照/失败环境/验收：** 必报 SPY TR、QQQ TR、完全相同 ETF 原组合、简单降低 ETF 权重加现金，以及等成本固定保护对照。慢涨/急涨时 collar、covered call 易落后；高隐含波动买保护昂贵；跳空、宽价差和指派会改变理论 payoff。[OIC Covered Call 说明](https://www.optionseducation.org/strategies/all-strategies/covered-call-buy-write)。至少 5 年可靠历史链、包含急跌与反弹、至少 60 个非重叠滚动周期；证据不足时延长观察。验收以预定保护成本内尾部损失改善、正确指派账本及保守报价仍可接受为主；收益不高于原组合时如实报告，不能把权利金收入单独当总回报。

## 10. S8：RD-Agent / 符号因子挖掘 + 集成

**定位和前置条件：** 自动化提出和实现因子，不授予它改验收标准、读测试集或直接下单的权限。微软 RD-Agent 提供因子和模型协同研发能力；它的官方实验收益不等于本项目美股 ETF 的预期收益。[微软官方 RD-Agent 仓库](https://github.com/microsoft/RD-Agent)。当前官方 README 标注支持 Linux，后续在 WSL2/Linux + 隔离运行环境部署；本阶段不安装、不调用模型 API。

**可用输入及表达式：** 第一轮只用与 S3 相同冻结的 ETF OHLCV 数据和基本特征，随后才加入合格 PIT 股票特征。允许 `rank / zscore / lag(k>=0) / rolling_mean / std / corr / min / max / + / - / * / safe_div`，最大表达式深度 4、窗口集合 `{5,10,21,63,126,252}`；禁止负 lag、全样本标准化、读取目标列和动态网络数据。

例子是候选研究表达式，不是被证明有效的 alpha：

```text
F1 = rank(mom_12_1) - rank(vol_63)
F2 = rank(R_21) * rank(volume / mean(volume,20))
F3 = -rank(R_5 - beta_SPY_126 * R_SPY_5)
```

**挖掘和验证预算：** 首次最多 30 个表达式，每个表达式有唯一 trial_id；后续增加预算必须在继续实验前重新登记，不能重置既有尝试计数。失败编译、重复因子、参数变体及人工筛选也进入试验账本。公式先做时点/单位/异常值检查，再在开发区间做 IC、分组收益、相关性、成本和稳定性筛选。相关性超过预先登记的 0.90 阈值时去重。只保留至多 5 个经济含义不同的候选，用等权排名集成作为第一版；复杂 stacking 必须用内层时间交叉验证生成 out-of-fold 输入。

**模型和组合复用：** 采用 S3 的标签、冻结训练切分、信号时点、top5 做多权重和成本条件；先冻结模型只比因子，再冻结因子只比模型，最后才讨论联合优化。集成不能因为包含更多分支就获得更多总风险预算。S8 信号由同一适配器交给 Qlib 和 LEAN，不让生成代码在两个引擎中自行改变执行逻辑。

**独立留出与失败规则：** Agent 仅获得训练/开发验证反馈，不得看到最终留出文件或指标。预先锁定的 24 个月最终留出仅对冻结产物运行一次。记录所有人工提示词变更和论文筛选来源，因为这些同样构成研究选择。多数候选失败是正常结果；无法战胜固定规则库时停止挖掘，不能靠继续访问测试区间得到“冠军”。

**最少证据/验收：** 至少满足 S3 的历史证据，加上完整试验账本、跨滚动窗口贡献、成本敏感性、多重试验诊断和相对 S3 的净增益。默认要求新增因子集在至少 2/3 滚动测试区间有正增益，10 bps 下净增益方向不反转，最终留出优于冻结基线且置信区间完整披露。DSR、PBO 或 IC 无一项能单独批准策略；独立留出失败即不晋级。

## 11. TradingAgents / LLM 事件覆盖扩展

现有 TradingAgents 的分析可作为独立覆盖层，先建立从现在开始的可审计纸面日志，再比较原策略、规则事件覆盖和 LLM 覆盖。保留 `source_published_at / fetched_at / analysis_finished_at / model_id / prompt_hash / input_hash / raw_output`；只有分析完成且来源在决策时可得的记录才可参与下一次交易决策。

首版仅允许把已存在目标仓位向下缩减，例如事件风险等级触发 `weight *= 0.5`，不允许凭文本输出突破策略总资金、单只或行业上限。风险标签阈值和持有天数在前瞻期前冻结。指标除收益还包括覆盖频率、缺失率、延迟和相对于简单关键词规则的增量。

使用今天的大模型读取旧新闻，不足以证明当年可交易 alpha：模型可能见过后续事实，新闻库可能含修订，调用到达时间不可还原。历史回放可以测试解析、接口和一致性；涉及收益的历史结果必须标为受污染风险的探索，不作为上线晋级证据。推荐先连续记录至少 60 个交易日验证管道，再累积更长前瞻样本判断有效性。

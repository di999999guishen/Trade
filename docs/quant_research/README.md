# 美股 ETF 量化研究与因子挖掘：项目开发文档

版本：1.0；编制日期：2026-09-17。状态：**方案与开发提示词已建立，量化平台尚未实现；本次没有运行策略回测，也没有实测超额收益。**

## 1. 你的需求与推荐结论

已按本次确认的偏好设计：**先用免费数据；美股上市 ETF 为主；每天计算信号、允许日线调仓；第一阶段做多；后续允许做空和期权；验证后才考虑购买数据。**

推荐在当前仓库旁路建立独立的 `quant_research/` 项目，以 **Qlib → 因子研究 / LightGBM → LEAN 复核与模拟交易** 为主线。现有 TradingAgents 继续负责研究解释和事件证据；组合收益由确定性的行情、信号、仓位、成交和费用计算。

Qlib 支持从信号到策略回测的研究流程，能够先做规则策略再增加模型。[Qlib 官方仓库](https://github.com/microsoft/qlib)。LEAN 提供独立的事件驱动引擎；引擎源码与云平台、CLI、数据订阅分别评估。[LEAN 官方仓库](https://github.com/QuantConnect/Lean)。

“争取跑赢美股指数”拆成两个目标，分别报告：

1. **绝对收益增强**：相同期间、美元、税前、含分红、扣交易成本后，收益是否超过 SPY；QQQ 作为独立副基准，不在结果出来后更换主基准。
2. **风险改善**：更低回撤、更高风险调整收益。这种改进可以成立，即使总收益没有超过 SPY，报告必须如实区分。

现在没有证据能保证哪套策略会跑赢。这里交付的是可验证的研发路线、策略假设与开发契约。

## 3. 三阶段技术路线

| 阶段 | 交付重点 | 工具与成本边界 |
|---|---|---|
| P0：免费 ETF MVP | 数据快照、SPY/QQQ基准、S1规则策略、成本压力、可复现报告 | yfinance + Parquet/DuckDB + Qlib；只使用本地计算与免费可访问数据；不启用 LLM |
| P1：因子平台 | S2多因子、S3轻量模型、时间滚动验证、实验登记 | Qlib表达式、LightGBM、MLflow；Optuna在固定实验预算内选用 |
| P2：可信度升级 | LEAN逐笔账本复核、前向模拟、必要时换高质量数据 | 直接部署LEAN开源引擎；数据购买按实际缺口决定，不自动订阅 |
| P3：扩展研究 | 股票PIT、做空、期权、自动因子研发 | 数据和成本条件满足才启用S4–S8；各自单独立项 |

Qlib 的依赖可能已包含 LightGBM/MLflow，“P0不训练模型”不代表绕过其正常依赖安装。采用稳定版本解析后冻结环境，避免修改现有 `.venv`。

## 4. 策略优先级

| 编号 | 策略 | 当前是否适合启动 |
|---|---|---|
| S1 | ETF 趋势过滤 + 相对动量轮动 | **第一优先**：免费数据足以做探索性检验 |
| S2 | ETF 多因子评分 + 风险预算 | 第二优先：与S1比较增益和交易成本 |
| S3 | ETF LightGBM 排序 | S1/S2完成后；少量ETF不适合堆高维模型 |
| S4 | 股票质量 + 动量 | 后续：需要历史可得的财务与动态股票池 |
| S5 | 财报公告后漂移 PEAD | 后续：需要历史预期、实际值和准确发布时间 |
| S6 | ETF 残差反转多空 | 后续：需要借券、融资和更保守成交假设 |
| S7 | ETF 期权保护与收益覆盖 | 后续：需要历史期权链、报价与指派模型 |
| S8 | RD-Agent 自动因子研发与集成 | 后续：已有可靠验证器和独立留出集才启用 |

日线调仓表示每天可以重新决定权重；**不意味着每天必须交易**。默认使用持仓缓冲、权重偏离阈值和换手上限，减少无效摩擦。

## 5. 第一轮应交付的具体结果

- 18只候选ETF及SPY/QQQ基准的数据覆盖、成立时间和公司行动检查；固定资产池仍标记选择偏差。
- SPY买入持有、QQQ买入持有、固定池等权、简单趋势及S1策略的同口径报告。
- 5 / 10 / 25 bps 单边成本情景；这些是测试假设，不是券商报价。
- 每日冻结信号、目标权重、组合净值、换手和排除原因；与订单回测的区别清楚可见。
- 至少一个离线可重现快照；未来数据更改不会影响过去信号。
- 明确的结论：继续、修改假设后重新登记、购买某项缺失数据、或停止该策略。

免费数据阶段只证明管线可运行及是否值得继续研究。更严格的盈利结论需要样本外验证、数据质量升级和前向记录。

# ETF 粗筛与 agents 决策修正（2026-09-15）

## 结论与已确认的问题

HOLD、减持占比高不能单独证明系统异常，也不能用增加 Buy 数量验证准确率。本轮确认并修正了以下问题：

1. `build_plan` 原来明确标记粗筛证据“仅在计划中，未注入 CLI”。运行时只有代码和日期传给 agents。现在将冻结快照来源、时间、规则版本、分项评分、大小单背离及冻结机会观察写入每个标的的 `screen_evidence.json`，通过 `--screen-evidence` 注入所有使用标的上下文的分析、研究、交易和风险节点。
2. Trader 原本使用三档交易动作，上下游使用五档评级。这是原来的设计取舍，不能据此断言造成偏空；现在提示词与结构化枚举都支持 Buy / Overweight / Hold / Underweight / Sell，减少中间层信息损失。
3. 未提供持仓却给出减仓比例的风险：现有 `reports/0700.HK_2026-07-30/5_portfolio/decision.md` 包含具体减仓和底仓比例。现在要求持仓操作附带条件，不能虚构仓位、成本或浮盈。
4. 明确区分“证据均衡”和“证据不足”两类 Hold；缺数据只降低信心，不自动作为看跌证据。保持减持与绝对价格下跌的语义区别。

证据变化会改变 checkpoint 标识，避免复用旧证据下的中间结论。历史报告、冻结筛选和评级结算记录不重写。

## 新的粗筛因子与权重

| 因子 | 权重 | 定义 |
|---|---:|---|
| 主力净流入占比 | 30% | 原有因子，截断到 ±30% 后归一化 |
| 成交额流动性 | 25% | 原有成交额对数分数 |
| 单日涨跌幅 | 10% | 原有因子，截断到 ±10% 后归一化 |
| 超大单与大单背离 | 10% | 原有背离因子 |
| 资金流／市值 | 10% | 净流入除以快照市值，±1% 截断为 ±1；不等同净申购 |
| 同类相对强度 | 15% | 单日涨幅减去同资产类别、同市场范围合格候选的中位涨幅，±5 个百分点截断为 ±1；至少需要 3 个有效同类样本 |

可用因子权重重新归一化；缺失涨跌幅和缺失同类比较均保留为空。非有限价格、成交额、市值被排除。规则算法版本从 3 升为 4，旧权重仍可通过配置显式恢复，但新算法仍保留数据质量修复。

这些是研究权重，并未通过收益优化或样本外验证。资金流相关因子彼此相关，动量与相对强度也相关，提示词明确禁止把它们当成多份独立确认。

原有机会观察中的 MA20/MA60、5/20 日收益、20/60 日回撤及数据可用性标记也随冻结证据传递。它们属于补充分析证据，本轮没有再重复加进粗筛权重。旧冻结报告未包含的历史指标保持缺失，不使用后来的数据补写。

## 后续评估方法

默认粗筛和量化申请仍为 20，大模型预算仍为 5，`skip_tradingagents=true` 保持原有运行设置。本轮未进行在线 LLM 重跑，不能声称预测准确率已提高。

应在刷新行情后按相同日期、同一候选集合、同一模型进行旧版／新版证据对照，分别记录评级、Hold 原因、5/20 日方向判断和条件性持仓操作；到期比较扣成本收益、回撤、方向覆盖率和各评级样本数。筛选规则本身另做按时间切分的样本外验证，不能仅比较 Buy 比例。

下一批可接入的独立数据：ETF 溢折价、基金份额净变化、底层指数相对收益、跟踪偏差、事件发布时间及相关性。当前缺少可靠、带时点的数据源，不能从成交资金流虚构净申购，也不能将缺失溢价记为零。ETF 市价与 NAV 的区别参考 [Investor.gov ETF 说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)；防止测试信息泄漏参考 [scikit-learn 官方说明](https://github.com/scikit-learn/scikit-learn/blob/main/doc/common_pitfalls.rst)。
